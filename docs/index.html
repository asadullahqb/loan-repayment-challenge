What we did (in plain English)

1. Predict who defaults

We trained a model that scores each applicant's chance of not repaying — using only what's known at application time (fraud score, loan terms, geography, history).

2. Price the loss

We measured how much is lost on a default (LGD 88%) and how much money is at risk (EAD), turning every prediction into a dollar figure.

3. Prove it makes money

We re-ran the last cohort with and without the model. Using it to reject the riskiest ~35% nearly tripled profit.

Limitations & next steps

  • Data limits: anonymized — no external credit bureau can join, so the model uses application-time features only.
  • Selection bias: the cohort is already-funded loans, not all applicants — the model understates risk on the full funnel.
  • Sample: single lender, 2014–2017 — results may not generalize across time or markets.
  • Next: add bureau data, macro overlays, and production drift monitoring (already scaffolded in tht/monitoring.py).
